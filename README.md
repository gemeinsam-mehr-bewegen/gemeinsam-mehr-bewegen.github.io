# Team-App (Gerüst)

Geschlossene Lern-App als Web-App. Dieses Projekt enthält nur die Hülle: Anmeldung über Telegram, Wartebildschirm, Admin-Seite und Grundaussehen.

Die Inhalte liegen nicht hier, sondern geschützt in einer Datenbank und sind nur für freigeschaltete Personen abrufbar.
